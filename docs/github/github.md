# GitHub

> [Git](https://git-scm.com/) is a version control program. It allows us to split work into isolated work branches, manage a history of changes, and combine work cleanly using a *merging* system. The projects that use git are known as *repositories*.

> [GitHub](https://github.com) on the other hand is a hosting site for those same repositories. You can work with Git using either the GitHub Desktop application or the Git Bash tool.

This section of the documentation outlines how to set up and use Git to collaborate on code and programs.

If you are looking for Git guidelines those are located in [Standards > Git]({{site.baseurl}}/docs/standards/git.md).

## Creating an Account

Before following any of the pages in this section for using GitHub, please make sure you have a GitHub account first to be able to access and contribute work. This can be done at [github.com](https://github.com/signup). We recommend using a personal email so that you have access to the account after you graduate.
